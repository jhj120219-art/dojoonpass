# 개발 원칙

이 문서는 검색 기능 구현의 단일 기준(Single Source of Truth)이다.
Claude Code는 본 문서를 우선적으로 따르며, reference 폴더의 HTML은 구현 참고 자료로만 사용한다.
분석보다 구현을 우선하며, 기능은 반드시 테스트 후 다음 단계로 진행한다.



# 목적

도준패스의 검색 기능을 탱크옥션 수준까지 구현한다.

본 문서는 검색 기능 구현의 단일 기준(Single Source of Truth)이다.

모든 구현은 본 문서를 기준으로 진행하며,
명시되지 않은 기능은 임의로 추가하거나 변경하지 않는다.
