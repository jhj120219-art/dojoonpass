프런트는 `result.data` 를 읽으므로 그 순간 화면이 빈다.

## 고친 것 ― 라우트에서 유도

라우트를 손으로 고르지 않고 앱에서 뽑는다(Sprint 108과 같은 방식 ―
이 FastAPI 버전은 `include_router` 결과를 평탄화하지 않으므로 감싼 것을 풀어서 센다).

```
   인증 필요 GET 중 200 응답 15개 대조
[PASS] 봉투 계약 대상이 충분히 있다(검사가 공허하지 않다)
[PASS] 봉투 모양을 벗어난 인증 GET 없음: []
```

### 판정 대상은 **200 응답만**이다

이 저장소에는 실패 응답이 두 형태 있고 **둘 다 의도된 상태**다.

```
error_response(code, msg)   -> HTTP 200 + {success:false, error:"CODE", ...}
raise HTTPException(...)    -> HTTP 4xx + {"detail": "..."}
```

없는 id 를 넣어 404가 나온 것을 봉투 위반으로 세면 **정상 동작을 결함으로 부르게 된다.**
처음 측정할 때 실제로 그 6건이 "★다름"으로 찍혔다 ― 검사에는 그 구분을 넣었다.
