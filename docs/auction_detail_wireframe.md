# 도준패스 - 권리분석 상세화면 와이어프레임

## 1. 화면 개요

| 항목 | 내용 |
|---|---|
| 화면명 | 물건 상세 (권리분석) |
| 경로(예시) | `/auction/[caseNumber]/[itemNumber]` |
| 플랫폼 | Next.js (Web) / Android WebView 대응 |
| 목적 | 투자자가 실제 입찰 여부를 판단하는 데 필요한 핵심 정보(사건정보/권리분석/원본문서)를 한 화면에서 제공 |

---

## 2. 레이아웃 구조 (Desktop / WebView 공통)

```
┌──────────────────────────────────────────────────────────────────┐
│  Header (사건번호 / 상태뱃지)                                        │
├───────────────────────────────┬────────────────────────────────────┤
│  [A] 기본정보 카드              │  [C] 문서 뷰어 영역                  │
│                                 │                                    │
├───────────────────────────────┤   - PDF 미리보기 / 다운로드           │
│  [B] 권리분석 카드              │                                    │
│                                 │                                    │
└───────────────────────────────┴────────────────────────────────────┘
```

- Mobile(WebView)에서는 A → B → C 순서로 세로 스택(Stack) 배치
- 각 카드는 독립 컴포넌트로 분리 (재사용 및 로딩 상태 개별 처리 목적)

---

## 3. [A] 기본정보 카드

```
┌──────────────────────────────────────────┐
│  사건번호      2024타경12345               │
│  물건번호      1                           │
│  ────────────────────────────────────    │
│  주소   서울특별시 ○○구 ○○동 000-00         │
│                [지도보기 아이콘]            │
│  ────────────────────────────────────    │
│  매각기일      2026.08.14 (금) 10:00       │
│  최저매각가격   350,000,000 원              │
│  유찰횟수      2회                         │
└──────────────────────────────────────────┘
```

### 표시 항목 상세

| 필드 | 데이터 소스(연동 예정) | 표시 형식 | 비고 |
|---|---|---|---|
| 사건번호 | 법원경매 공고 원본 | `YYYY타경NNNNN` | 필수, 헤더에도 노출 |
| 주소 | 매각물건명세서 | 도로명/지번 병기 | 지도 아이콘 클릭 시 별도 지도 모달(선택) |
| 물건번호 | 매각물건명세서 | 숫자 | 단일 사건 내 복수 물건 시 구분자 |
| 매각기일 | 법원 공고 | `YYYY.MM.DD (요일) HH:mm` | 임박 시 D-day 뱃지 |
| 최저가 | 법원 공고 | 원화 3자리 콤마 | 억/만원 단위 병기 옵션 |
| 유찰횟수 | 법원 공고 | `N회` | 0회는 "신건" 뱃지로 대체 표시 |

## 4. [B] 권리분석 카드

```
┌──────────────────────────────────────────┐
│  권리분석                                  │
│  ────────────────────────────────────    │
│  위험도        ● 중간            [뱃지]    │
│  인수금액       0 원 (인수사항 없음)         │
│  명도난이도     ● 어려움           [뱃지]    │
│  ────────────────────────────────────    │
│  대항력        있음 / 없음                  │
│  배당요구       배당요구종기 내 신청 완료      │
│  ────────────────────────────────────    │
│  특이사항                                  │
│  · 선순위 임차인 존재, 대항력 여부 확인 필요   │
│  · 유치권 신고 있음 (성립 여부 미확정)        │
└──────────────────────────────────────────┘
```

### 표시 항목 상세

| 필드 | 정의 | 표시 형식 | 비고 |
|---|---|---|---|
| 위험도 | 권리관계 복잡성에 따른 정성적 구분 | 낮음/중간/높음 (색상 뱃지) | **점수(숫자)화 금지** — 등급 라벨만 사용 |
| 인수금액 | 낙찰자가 추가로 인수해야 하는 금액 | 원화, 없으면 "인수사항 없음" | 등기부/현황조사서 기반 산출 근거 각주 필요 |
| 명도난이도 | 점유자 현황 기반 정성적 구분 | 쉬움/보통/어려움 (색상 뱃지) | 현황조사서 점유관계 연동 |
| 대항력 | 임차인의 대항력 성립 여부 | 있음/없음/판단보류 | 확정일자·전입일 비교 로직 필요(백엔드) |
| 배당요구 | 배당요구 여부 및 기한 준수 여부 | 텍스트 서술형 | 배당요구종기일 병기 |
| 특이사항 | 유치권/법정지상권/분묘기지권 등 | 불릿 리스트 | 항목별 원본 문서 링크 제공 |

> ⚠️ **개발 제약사항 반영**: 이 카드는 "권리 상 사실관계"를 요약 표시하는 용도이며, 투자점수·AI추천·수익률 등 투자 판단을 대신하는 산출물은 포함하지 않는다. 위험도/명도난이도는 등급 라벨(낮음/중간/높음)만 사용하고 점수·순위·추천 문구를 노출하지 않는다.

## 5. [C] 문서 뷰어 영역

```
┌──────────────────────────────────────────┐
│  관련 문서                                 │
│  ────────────────────────────────────    │
│  📄 매각물건명세서.pdf        [보기] [다운로드]│
│  📄 감정평가서.pdf            [보기] [다운로드]│
│  📄 현황조사서.pdf            [보기] [다운로드]│
│  ────────────────────────────────────    │
│  [선택된 문서 PDF 미리보기 영역]              │
│                                            │
└──────────────────────────────────────────┘
```

### 문서 목록 상세

| 문서명 | 형식 | 상태 표시 | 비고 |
|---|---|---|---|
| 매각물건명세서 | PDF | 수집완료/수집중/미수집 | 원본 수집 파이프라인 1순위 대상 |
| 감정평가서 | PDF | 수집완료/수집중/미수집 | 최저가 산정 근거 확인용 |
| 현황조사서 | PDF | 수집완료/수집중/미수집 | 점유관계·명도난이도 판단 근거 |

- 문서 미수집 상태일 경우 카드/버튼 비활성화 + "수집 중" 안내
- Web: 브라우저 내 PDF 뷰어(iframe) / Mobile WebView: 네이티브 PDF 뷰어 인텐트 호출

## 6. 상태(State) 정의

| 상태 | 설명 | UI 처리 |
|---|---|---|
| Loading | 데이터 요청 중 | 카드별 스켈레톤 UI |
| Partial | 일부 문서 미수집 | 해당 항목만 "수집 중" 표시, 나머지 정상 표시 |
| Error | 수집 실패/데이터 없음 | 에러 카드 + 재시도 버튼 |
| Complete | 전체 정상 수집 | 전체 카드 정상 표시 |

---

## 7. 반응형 분기 기준

| 브레이크포인트 | 레이아웃 |
|---|---|
| ≥ 1024px | 좌측 A+B / 우측 C 2컬럼 |
| 768px ~ 1023px | A+B 상단 2컬럼, C 하단 전체 폭 |
| < 768px (WebView 포함) | A → B → C 세로 1컬럼 스택 |

## 8. 후속 논의 필요 사항 (Open Questions)

1. 위험도/명도난이도 등급 산정 로직(백엔드) 확정 필요 — 라벨 기준(낮음/중간/높음) 정의
2. 인수금액 계산 근거를 프론트에서 각주로 노출할지 여부
3. PDF 원본 미수집 시 대체 텍스트(OCR 요약) 제공 여부
