## 1. `audit_asset_integrity.py` — 읽기 전용 자산 무결성 감사

이 저장소의 `*_dryrun.py` 관례를 따른다. **절대 고치지 않는다** — 무엇을 지우고 무엇을
다시 받을지는 상황마다 다르고, 잘못 지우면 되돌릴 수 없다. 발견과 조치를 분리한다.

```bash
python audit_asset_integrity.py            # 0=정상 / 1=어긋남 / 2=실행 실패
python audit_asset_integrity.py --selftest # 감사기가 눈이 멀지 않았는지 확인
```

### 일곱 가지를 본다 — 양방향으로

```
[1] auction_image -> 파일          DB 가 가리키는 사진이 실제로 있는가
[2] 디스크 <-> auction_image 집합   순번 집합이 정확히 같은가 (고아 파일 = 거짓 개정의 씨앗)
[3] document_status READY -> 파일   READY 인 문서의 **필요한 파일이 전부** 있는가
[4] doc_raw -> 파일                기록된 경로가 실재하는가
[5] 큐 <-> 화면 상태               done 인데 미완료 / 대기인데 READY
[6] 디스크 -> DB (문서)            대응 물건이 없는 문서 파일이 있는가
[7] 큐 -> 물건                     대응 auction_item 이 없는 큐 행이 있는가
```

[1]~[4] 는 **DB 기준**, [6][7] 은 **반대 방향**이다. 한 방향만 보면 "아무도 가리키지
않는 것"은 영원히 안 보인다 — 사진은 [2] 가 그 방향을 보고 있었지만 문서·큐에는 없었다.

## 3. 감사기가 눈이 멀지 않았는지 스스로 확인한다

감사 스크립트는 조용히 아무것도 안 보게 되기 쉽고, **그 상태는 정상과 겉으로 완전히
같다.** 그래서 `--selftest` 가 운영 DB **사본**에 결함을 심어 잡히는지 본다.

```
[PASS] 사본 기준선은 어긋남 0
[PASS] 파일 없는 사진 행을 잡는다
[PASS] READY 인데 파일 없는 문서를 잡는다
```

## 4. ★ 이번에 가드가 내 실수를 세 번 잡았다

이 Sprint 에서 **내가 만든 결함 셋을 전부 기존 방어가 잡았다.** 기록해 둘 값어치가 있다.

### (1) 추적 파일이 미추적 파일을 import 했다

감사기 자체 검사를 처음에는 `test_asset_pipeline.py` 에 넣었다.
`test_schema_hygiene.py` 의 **"추적 파일이 미추적 파일을 import하지 않는다"** 가 즉시
잡았다 — `audit_asset_integrity.py` 는 아직 미추적이고, 그 상태로 커밋하면
`ModuleNotFoundError` 로 API 가 부팅되지 않는다(BUGS #105 와 같은 상태).

`git add` 는 승인 영역이므로 **가드를 우회하지 않고 의존 자체를 없앴다** —
자체 검사를 감사기 안(`--selftest`)으로 옮겼다.

### (2) 감사기가 DB 경로를 **복사**해 왔다

`from storage.database import DB_PATH` 는 그 순간의 **스냅숏**이다. 그래서 자체 검사가
스크래치 DB 를 가리켜도 감사기는 **실 DB 를 읽었다** — 결과가 통째로 무의미했다.
`db_path()` 로 매번 읽도록 고쳤다. `DOCUMENT_ROOT` 도 같은 이유로 `_document_root()`.

### (3) 고아 검사가 경로 정규화를 빼먹어 **거짓 경보 36건**을 냈다

디렉터리 이름은 `sanitize_path_segment()` 를 거친 값인데, DB 의 원본 `case_no` 와 그대로
비교했다. 실데이터에 `2008타경25092 / 2015타경19958`(중복사건) 같은 값이 실제로 있고
디스크에는 `..._ ...` 로 저장된다.

```
정규화 빼먹었을 때   "고아" 37건   <- 36건이 거짓 경보
쓰는 쪽과 같은 함수  "고아"  1건   <- 진짜
```

**감사기가 거짓 경보를 내는 것은 아무 경보도 안 내는 것만큼 나쁘다** — 다음부터
아무도 안 본다. 규칙을 베끼지 않고 **쓰는 쪽과 같은 함수**를 쓰는 것이 답이다
(Sprint 146 이 같은 자리에서 배운 것).
