# Customer Problem

정보가 없어서가 아니다. **한 물건을 판단하기까지의 과정이 길다.**

검색 -> 자료 확인 -> 권리 확인 -> 임차인 확인 -> 문서 확인 -> 시세 확인 -> 현장 확인 -> 판단

이 과정이 여러 사이트·문서·수첩에 흩어져 있어서,
본업이 있는 사람은 한 물건을 끝까지 보지 못하고 중간에 놓는다.

---

# Solution

**경매 의사결정에 드는 시간을 줄인다.**

DISCOVER -> REVIEW -> FIELD -> DECIDE 를 한 곳에서, 밖으로 나가지 않고.

AI 는 그 시간을 줄이기 위한 **수단**이지 그 자체가 상품이 아니다.
