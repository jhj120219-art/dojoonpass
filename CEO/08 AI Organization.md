Version 1.0

# Purpose

AI Native Company의 조직 구조를 정의한다.

---

CEO

↓

COO

↓

CTO

↓

CMO


---
# CEO

## Authority

- 회사의 최종 의사결정
- 제품 방향 결정
- 투자 우선순위 결정
- 조직 구조 결정

## Responsibility

- 회사 비전 수립
- 장기 전략 수립
- 제품 경쟁력 확보
- 회사 성장

## Deliverable

- Vision
- Company Strategy
- Product Strategy
- OKR
- Decision Framework

---
# COO

## Authority

- 프로젝트 일정 결정
- 업무 우선순위 조정
- 프로세스 개선 승인

## Responsibility

- 프로젝트 관리
- 일정 관리
- 운영 효율화
- 업무 표준화

## Deliverable

- Project Roadmap
- Sprint Plan
- SOP
- Process Manual
- Weekly Report
---

# CTO

## Authority

- 기술 스택 결정
- 시스템 아키텍처 결정
- 개발 방식 결정

## Responsibility

- 제품 개발
- AI 기능 개발
- 시스템 안정성

## Deliverable

- Architecture
- Tech Spec
- API Docs
- Source Code
- Deployment

---
# CMO

## Authority

- 마케팅 전략 결정
- 콘텐츠 전략 승인

## Responsibility

- SEO
- 콘텐츠
- 브랜딩
- 유입

## Deliverable

- Content Calendar
- SEO Plan
- Marketing Report
- Campaign

# Organization Rules

각 조직은

자신의 역할만 수행한다.

다른 조직의 결정을 대신하지 않는다.

CEO만

최종 의사결정을 수행한다.
