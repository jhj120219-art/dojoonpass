06_Content_Candidate_Pool.md

이 문서는

"오늘 무엇을 만들 것인가?"

를 결정하는 문서입니다.

AI는 여기서 하루 수백 개의 아이디어를 만들고, 그중 상위 몇 개만 콘텐츠가 됩니다.

목적(Mission)

매일 다양한 데이터 소스에서 콘텐츠 후보를 수집하고, 점수화하여 제작 우선순위를 결정한다.

Input
법원경매 데이터
온비드 데이터
부동산 뉴스
경제 뉴스
Google Trends
네이버 데이터랩
Threads
X
커뮤니티
내부 검색 로그
사용자 관심 목록
Output

매일 Content Candidate TOP 50

예시

Rank	제목	Score	Recipe 추천
1	감정가 12억 → 5억	96	Recipe_003
2	오늘 최고 할인 TOP10	95	Recipe_001
3	서울 신규 경매	92	Recipe_008
